Switch between Deskgear and OBI

OBI diagnoses Makita batteries. Deskgear turns the same JC3248W535 into a desk display. With one firmware in each slot, you can switch by rebooting.

  1. Download the update file, firmware.bin, below.
  2. Connect the device to Wi-Fi and open its firmware update menu. On the same Wi-Fi network, visit the address on the display and sign in.
  3. Select the file, check the PXL product label and version, then upload. The running slot is preserved. The firmware in the other slot is replaced.
Download update BIN

To switch back, open Settings → Firmware update in Deskgear and select OBI if it is listed in the other slot. For OBI downloads and instructions, visit MAYDAY OBI ↗

USB installation and recovery

For a blank board or recovery. The factory image can overwrite existing slots and settings. Disconnect the battery and connect a USB data cable using Chrome or Edge on a computer.
